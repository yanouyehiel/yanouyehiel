## À propos

Développeur Full-Stack et consultant IT basé à Douala, Cameroun. Je conçois et je livre des applications web, mobiles et des plateformes back-end complètes pour des clients variés, de la maquette au déploiement.

- 💼 Développeur **expérimenté**, en mission simultanée sur plusieurs projets, dont certains sont utilisés aujourd'hui par des milliers d'utilisateurs
- 🛠️ Stack principale : Spring Boot (Java), TypeScript / Node.js, Next.js, React Native
- ⚙️ DevOps sur VPS Linux : Nginx, MySQL, Redis, pipelines CI/CD, Docker
- 🤝 Je suis prêt à collaborer avec vous
- 📍 Douala, Cameroun
